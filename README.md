# 💰 Expense Tracker

A modern and user-friendly expense tracking application built to help users manage their finances, monitor income and expenses, and understand their spending habits through an interactive dashboard.

## 🌐 Live Demo

🚀 **Try the application here:**  
[Expense Tracker – Live Website](https://expense-tracker-woad-nu-26.vercel.app/)

## ✨ Features

- 🔐 **User Authentication:** Firebase authentication integration.
- 📊 **Interactive Dashboard:** View financial information in one place.
- 💵 **Income Tracking:** Monitor income and financial activity.
- 💸 **Expense Management:** Keep track of spending and expenses.
- 📅 **Monthly Statements:** Review monthly financial summaries.
- 📈 **Financial Overview:** Understand income and spending patterns.
- 🎨 **Modern Interface:** Clean design with a dark-themed dashboard.
- 📱 **Responsive Design:** Designed for convenient use across different screen sizes.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** CSS and utility-based styling
- **Authentication:** Firebase
- **Programming Language:** JavaScript (JSX)
- **Deployment:** Vercel
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd expense-tracker
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Firebase

Create a Firebase project and configure the authentication provider required by the application.

Set up the necessary Firebase environment variables using the variable names expected by your `firebase.js` file.

Keep sensitive credentials out of your public repository.

### 5. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.

## 🏗️ Build for Production

Generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🚀 Deployment

This application is deployed using Vercel.

The deployment workflow includes:

1. Uploading the project source code to GitHub.
2. Importing the GitHub repository into Vercel.
3. Configuring the required environment variables.
4. Building and deploying the application.
5. Accessing the application through its live URL.
